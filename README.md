# thd-factory-flopbus
### Tu viaje seguro, vayas donde vayas

## 1. Descripción del proyecto

**FlopBus** es un proyecto académico que desarrolla la propuesta de digitalización de una empresa ficticia dedicada al sector de la logística y el transporte de viajeros mediante autobuses.

El proyecto analiza cómo las Tecnologías Habilitadoras Digitales (THD) pueden mejorar la gestión de flotas, la seguridad, el mantenimiento de los vehículos, la planificación de rutas y la sostenibilidad de la empresa.

La web presenta las tecnologías seleccionadas, sus aplicaciones y la relación entre los entornos **IT (Tecnologías de la Información)** y **OT (Tecnologías de Operación)**.

## 2. Objetivos

- Identificar y analizar diferentes Tecnologías Habilitadoras Digitales.
- Comprender las diferencias entre los entornos IT y OT.
- Estudiar cómo se pueden integrar ambos entornos.
- Proponer soluciones tecnológicas aplicables al transporte de viajeros.
- Analizar los beneficios de la digitalización en la eficiencia, seguridad y sostenibilidad.
- Presentar un caso práctico de transformación digital en una empresa de autobuses.

## 3. Tecnologías Habilitadoras Digitales

El proyecto contempla las siguientes tecnologías:

| Tecnología | Solución propuesta | Aplicación |
|---|---|---|
| Ciberseguridad | FlopSafe Bus-Shield | Protección de sistemas, redes y datos. |
| Cloud Computing | FlopCloud Transit | Almacenamiento y gestión de información en la nube. |
| Materiales Avanzados | FlopLight Chasis Kit | Desarrollo de componentes más ligeros y resistentes para autobuses. |
| Internet de las Cosas (IoT) | FlopBus SmartFleet | Monitorización de vehículos mediante sensores conectados. |
| Gemelo Digital | FlopTwin City | Representación virtual de autobuses y sistemas para analizar su funcionamiento. |
| Inteligencia Artificial | FlopAI RouteOptimizer | Optimización de rutas y apoyo a la toma de decisiones. |

## 5. Integración IT/OT

La transformación digital de FlopBus se basa en la colaboración entre dos entornos:

- **IT (Information Technology):** gestiona los datos, las aplicaciones, las redes, los servidores y los sistemas de información de la empresa.
- **OT (Operational Technology):** supervisa y controla los vehículos, sensores y otros sistemas físicos relacionados con las operaciones.

La integración de ambos permite aprovechar los datos obtenidos por los autobuses para mejorar el mantenimiento, optimizar las rutas, reducir costes y aumentar la seguridad.

## 6. Tecnologías utilizadas

El proyecto se desarrolla mediante:

- **HTML5:** estructura y organización del contenido de las páginas web.
- **Git:** control de versiones del proyecto.
- **GitHub:** alojamiento del repositorio y colaboración en el desarrollo.

La web se ha planteado utilizando HTML, sin hojas de estilo CSS ni JavaScript.

## 7. Caso práctico

El proyecto incluye un caso práctico ficticio de transformación digital aplicado a una empresa de transporte denominada **Autocares Sierra Nevada S.L.**

Se estudian posibles mejoras en aspectos como:

- Tiempo de planificación de rutas.
- Costes de gestión informática.
- Incidentes de seguridad.
- Tiempo de detección de averías.
- Costes de mantenimiento.
- Consumo de combustible.
- Emisiones de CO₂.

Los datos y resultados de este caso son estimaciones inventadas con fines académicos y no representan resultados reales de una empresa.

## 8. Instalación y visualización

No es necesario instalar dependencias ni configurar un servidor para consultar el proyecto.

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/candyoen/thd-factory-flopbus.git
   ```

2. Acceder a la carpeta:

   ```bash
   cd thd-factory-flopbus
   ```

3. Abrir el archivo `index.html` en un navegador web.

También se puede descargar el repositorio desde GitHub y abrir directamente la página principal.
